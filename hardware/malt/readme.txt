MALT IDE
========

MSX 8255 PPI IDE board that is based on the Eurocard Bus DiskIO V3 PPIDE design
for retrocomputers.

It uses the same 8255 PPI chip as the MSX BEER interface but the IDE control
signals are implemented in a more robust way.

Note: see patch document for the pcb version 1.1, these changes will be included 
in the upcoming pcb version 1.2
